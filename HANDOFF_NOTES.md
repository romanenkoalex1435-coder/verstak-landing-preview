# Передача сайта Сане

Утверждённое направление: **09 — Quiet Navigation System**.

## Запуск

Откройте `index.html` в браузере. Сайт работает без сборки и без внешних зависимостей.

## Структура

- `index.html` — страница сайта.
- `assets/site-v09/core.js` — конструктор, галерея, прототип и форма.
- `assets/site-v09/data.js` — цены, модули и демонстрационные данные.
- `assets/site-v09/fonts/` — локальные шрифты.
- `assets/site-v09/img/` — изображения демонстрационных кейсов.

## Важные незакрытые решения

1. `window.SX_FORM_ENDPOINT` пока не задан. Форма честно сообщает, что онлайн-отправка недоступна, сохраняет введённые данные и предлагает скопировать заявку.
2. Нужно добавить утверждённую политику обработки персональных данных.
3. Нужно утвердить название компании и контакт для связи.

Не показывать успешную отправку заявки без явного подтверждения сервера.
